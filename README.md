# Khader Mohideen — Portfolio

Senior Graphic & Packaging Designer, Dubai.

## Run locally
Serve the folder with any static server (opening `index.html` directly from disk may block assets):

```
npx serve .
# or
python3 -m http.server
```

## Deploy on GitHub Pages
1. Push this folder's contents to the root of a repository.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Site goes live at `https://<username>.github.io/<repo>/`.

## Structure
- `index.html` — the site
- `support.js` — runtime (keep next to index.html)
- `img/` — portfolio images, portrait, CV pages
- `cv/` — downloadable CV PDF
